# Retail Sales & Profitability Analysis

## Project Overview
An exploratory data analysis project investigating retail sales, profit, discounts, product categories, customer segments, and regional performance.

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Kaggle Notebooks

## Dataset
Sample Superstore dataset from Kaggle.

Source: https://www.kaggle.com/datasets/bravehart101/sample-supermarket-dataset

## Data Cleaning
- Original records: 9,994
- Exact duplicate rows removed: 17
- Cleaned records: 9,977
- Missing values: 0

## Key Findings
- Total Sales: $2,296,195.59
- Total Profit: $286,241.42
- Overall Profit Margin: 12.47%
- Technology had the highest total sales and profit among categories.
- The West region had the highest total sales and profit.
- Tables recorded the lowest total profit.

## Analysis Performed
- Dataset inspection and data cleaning
- Sales and profit KPIs
- Category, region, and customer-segment analysis
- Sub-category profitability analysis
- Six charts and a correlation heatmap
- Business recommendations

## Limitations
The dataset has no order-date column, so time-based trends cannot be analyzed. Correlation does not prove causation.
